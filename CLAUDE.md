Read `AGENTS.md` in this directory first. It is the short version of everything below: setup
commands, the checks that must pass, and the constraints in this project that look like
omissions but are deliberate — no hardcoded prices, one counted recommendation per resource,
read-only AWS access.

It also indexes the rest of the documentation. Reach for `DEVELOPMENT.md` when adding a service
or a rule, `TROUBLESHOOTING.md` when something breaks, `DECISIONS.md` before changing a design
choice, `ARCHITECTURE.md` for how the pieces fit, and `STATE.md` for what the last scan of the
real account found.
